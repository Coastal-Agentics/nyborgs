# Nyborgs, a Coastal Agentics project

The landing page for **Nyborgs**: Nye Warburton's customizable agents, with round cream heads, dot eyes and chunky primary-colour yarn hair. Every Nyborg gets the same point budget, and cosmetics never affect stats. One Nyborg can train in any arena: tank and racing today, more later.

Served by GitHub Pages at <https://coastal-agentics.github.io/nyborgs/> from the root of `main`. The page links to the live games in [Coastal-Agentics/arena](https://github.com/Coastal-Agentics/arena):

- Tank Arena: [/arena/arena.html](https://coastal-agentics.github.io/arena/arena.html)
- Kart racing: [/arena/arena.html?game=racing](https://coastal-agentics.github.io/arena/arena.html?game=racing)
- Nyborg Customizer: [/arena/customizer.html](https://coastal-agentics.github.io/arena/customizer.html)
- Customize a match: [/arena/arena.html?tab=customize](https://coastal-agentics.github.io/arena/arena.html?tab=customize)
- Field notes: [/arena/fieldnotes.html](https://coastal-agentics.github.io/arena/fieldnotes.html)

Company site: <https://coastal-agentics.github.io/> ([Coastal-Agentics/coastal-agentics.github.io](https://github.com/Coastal-Agentics/coastal-agentics.github.io)). Coastal Agentics: behavioral design for agents, from Savannah, Georgia.

## What's here

| File | Purpose |
| --- | --- |
| `index.html` | The page: shared Coastal Agentics header and footer, what a Nyborg is, links to the live games. Inline CSS, no build step |
| `nyborgs.svg` | Header art: three Nyborgs (generated by `tools/gen-nyborgs.py`) |
| `logo.svg`, `logo-wordmark.svg`, `favicon.svg` | Coastal Agentics mark, wordmark and favicon, copied from the company site |
| `flock.js` | The company site's quiet background flock |
| `tools/shoot.py` | Screenshots the page and checks the live game links in headless Chromium |
| `.nojekyll` | Tells Pages to serve the files as-is |

## Links

Links between the three sites are root-relative (`/`, `/nyborgs/`, `/arena/`), so they keep working when the company site moves to its own domain. Local preview of the whole set: put the company site at the root of a folder, this repo at `nyborgs/` and arena's `web/` at `arena/`, then run `python3 -m http.server` in that folder.
